# Subprocessor List

**Version**: 1.0  
**Last Updated**: 2026-09-30

This document lists all subprocessors (third parties who process customer data on behalf of Durkan/Nordstrand in connection with Paperclip services).

## Overview

A subprocessor is any third party who processes personal data or customer data as instructed by Durkan/Nordstrand in providing Paperclip services. This includes cloud infrastructure providers, backup services, monitoring tools, and other service providers.

All subprocessors are bound by contractual data processing agreements ensuring they:
- Process data only as instructed
- Maintain appropriate security
- Respect data subject rights
- Notify us of data breaches

## Subprocessor Changes

We may add or remove subprocessors as needed. We will:

1. **Notify customers** of material changes at least 30 days in advance
2. **Obtain consent** or provide opportunity to object per Data Processing Agreement
3. **Update this list** within 7 days of any change
4. **Maintain data agreements** with all new subprocessors before processing begins

## Customer Data Definition

For this list, "customer data" includes:
- Company configurations and metadata
- Agent deployment information
- Execution logs and transcripts
- API keys and secrets (encrypted)
- User account information
- Any data uploaded or provided by customers

## Data Processing Obligations

All subprocessors are contractually bound to:

- **Confidentiality**: Treat data as confidential
- **Security**: Implement appropriate technical and organizational measures
- **Limitations**: Process data only as instructed by Durkan/Nordstrand
- **Subject Rights**: Assist with GDPR/CCPA subject access requests
- **Breach Notification**: Notify us immediately of security breaches
- **Audit Rights**: Allow audits and assessments of security practices
- **Sub-sub-processing**: Require prior consent before using additional subprocessors

## Vendor Risk Assessment

All subprocessors undergo security assessment including:

- Security certifications (SOC 2, ISO 27001, etc.)
- Data encryption practices
- Access controls and authentication
- Incident response procedures
- Financial stability and reputation
- Compliance certifications

## Objection Process

If you have concerns about a subprocessor:

1. Review the Data Processing Agreement
2. Contact our legal team within 30 days of notification
3. We will work with you to address concerns
4. In limited cases, you may have right to object per DPA
